# VideoEditor 2.0 — автомонтаж эпизодов Honest Lies

> Стартовый файл. Claude читает его в начале каждой сессии в этой папке.
> Один канал — **Honest Lies**. Стиль зашит, мастера настройки нет.

## Файлы проекта
| Файл | Что внутри | Кто правит |
|---|---|---|
| `CLAUDE.md` | роль, порядок работы, правила | Nurlan + Claude по согласованию |
| [`STYLE.md`](STYLE.md) | стиль монтажа: цвета, шрифты, титры, темп, переходы | Nurlan |
| [`LESSONS.md`](LESSONS.md) | уроки после каждого эпизода | Claude пишет, Nurlan утверждает |
| `keys.json` | ключи API | только Nurlan |
| `data\places.json` | места → координаты для карт | растёт на шаге 0 из `cast.json`, по согласованию |
| `data\countries.json` | страны → язык поиска + слова-признаки | растёт на шаге 0 из `cast.json`, по согласованию |

Стиль пока взят из AutoEdit (см. `STYLE.md`). Брендбук Honest Lies (`honest-lies\channel\style\branding.md`) подключим после отладки — только по решению Nurlan.

## Общение
- По-русски, коротко. Экранный текст в ролике — только английский.
- Пользователь может не помнить порядок шагов: веди сам, говори, что сейчас происходит и что нажать.
- Перед командой, которая что-то устанавливает или скачивает, — одной строкой сказать, что делаешь.
- Всё ставить и кэшировать на **D:** (на C: мало места).

## Когда что делать
- **«Новый эпизод: ep-N»** → раздел «Работа над эпизодом».
- **«Поменяй стиль …»** → правка `STYLE.md` по согласованию, проекты не пропадают.
- **Вопрос о работе программы** → ответить по `README.md`.
- **Начало каждой сессии** → прочитать `STYLE.md` и `LESSONS.md`.

## Где лежат материалы эпизода
Папку эпизода со всеми подпапками создаёт проект **hl-script** (`production\tools\new_episode.py N slug`), с EP-08.
```
D:\YouTube-Studio\production\honest-lies\ep-N\
  00-script\clean-script.txt  текст озвучки: те же слова, что в ElevenLabs, без тегов, пауз,
                              фонетики и заголовков — ЕДИНСТВЕННЫЙ вход этапа 1 (hl-script, фаза 7)   (читаем)
  01_vo\            озвучка к этапу 2 (скилл elevenlabs-vo): vo_01…vo_NN.mp3 + vo_outro.mp3 —
                    склеиваются по порядку имён с паузой 1 с; подпапки (_probe\) не читаются  (читаем)
  02_characters\    cast.json — реестр: люди, места (lat/lon), страны, объекты               (читаем)
                    + фото Nurlan <id>_01.jpg… по id из реестра — свои кадры людей и мест
  03_generated\     гравюры, Veo, картинки по заданию [КАРТИНКА] — свои кадры                (читаем)
  04_music\         фоновая музыка эпизода                                                   (читаем)
  05_footage\       архив и сток — свои кадры                                                (читаем)
  06_montage\       работа программы + готовые версии ep-N_vK.mp4 в корне                     (пишем)
  07_thumbnail\     обложка — не наше
  09_final_assets\  общая с Video-Wrapper: наш только ep-NN-final.mp4 (ep-08-final.mp4)      (пишем)
                    подпапки v-1\, v-2\ … — пакеты упаковки Video-Wrapper: НЕ трогать
```
Программа пишет **только в `06_montage\` и файл `09_final_assets\ep-NN-final.mp4`**. Остальное не удалять, не переименовывать, не менять.
Эпизоды до EP-07 — старая структура; программа рассчитана на новую.
В папке `VideoEditor_2.0` — только код и настройки, данных эпизодов там нет.

## Работа над эпизодом
Ты — режиссёр и монтажёр. Работа идёт в **два этапа**: сначала только текст, озвучка — потом.
Nurlan делает озвучку в ElevenLabs параллельно, не торопясь.

### Порядок, который сработал (EP-10, Nurlan: «2 всего ручного — это совсем ничего»)
Вести эпизод так, в одной сессии в папке `VideoEditor_2.0`, без лишних вопросов:
1. `prepare` → `passport` → «да» Nurlan → `passport --apply`.
2. Озвучка (2б) — разметка тегами сразу → экран с ценой → «ок» → все куски одним заходом (eleven_v4).
3. `refs` в фоне, пока пишется разметка `script.txt` (каждая фраза — не короче ~2 с; лица частных людей — только силуэт/со спины).
4. `tools\shots_from_script.py ep-N` → `gen` всех `[КАРТИНКА]` → лист глазами → брак (логотипы, похожие на реальных людей лица) — `gen --shots … --force` → `[СЦЕНА: N-g]`.
5. Лист `person_refs.jpg` глазами (не тот человек — выбрать из `refs\cand\`) → `regravure`.
6. `index` → `find` в фоне (~1 ч) → `found_sheet.jpg` глазами → брак удалить из `media\` и `found.json`. В сводке Nurlan — таблица из `work\find_report.txt` (какой источник сколько нашёл, одобрил, скачал; кто заблокирован). Источники — `tools\sources\<имя>.py`, порядок и выключение — `settings.json` → `finder` → `sources` / `off`; менять только с согласия Nurlan. DuckDuckGo (`ddg`) и Tavily (`tavily`, запасной: только если ddg ничего не дал) — только образцы `refs\s_<шот>_N` для ReGen (права неизвестны, в ролик напрямую нельзя); спрашиваются, лишь когда свободных кадров на шот не хватило. Tavily — 1000 бесплатных кредитов в месяц, счётчик `data\tavily_usage.json`, на 950 сам останавливается; расход за месяц — в сводке. Каждый `find` дописывает журнал `data\find_history.jsonl` + `data\find_requests.jsonl`; **в конце эпизода** — `ve.py findstats` → в `LESSONS.md` раздел «поиск» с предложениями (выключить пустой источник, поменять формулировки запросов…); меняю настройки и код только после «да» Nurlan.
6а. `ve.py fill ep-N` — сразу после `find`, без остановки на Nurlan: шоты с образцом в `refs\` (закрытые права, DuckDuckGo, Tavily) → `ep-N-shots.json` → ReGen → совсем пустой шот с оценкой ≥ 7 сам получает `[СЦЕНА: N-1-rg]` в `script.txt` (запрос — строкой `# найти было:`). `work\fill_sheet.jpg` — глазами; «на просмотр» (частично закрытые, оценка < 7) решаю сам. Расход картинок эпизода — в итоге; от $5 — сказать Nurlan (лимитов нет: ~$2 обычно, $3 нормально).
7. Пустые шоты — **сразу Gen** (сцена без лица: со спины, интерьер, здание), видео-шоты — `kind: любое`. Nurlan в `to-find-manually.json` достаются **только портреты**, которых нет нигде (EP-10: Захарский и Белл — одной картинкой).
8. `analyze` → `empty` → `tools\music_stats.py ep-N` → `voice_parts.json` + `music_plan.json` по `sound-vo.md` → `plan` → `tools\plan_check.py ep-N` → правки → сводка → «рендер».
9. `render` в фоне → `check` по частям → `ep-N_description.txt`.

### Этап 1 — только сценарий (озвучки ещё нет)

**0. Паспорт эпизода — из реестра `02_characters\cast.json`** (`ve.py passport`)
Команда собирает черновик `06_montage\context.json` из реестра (эпоха, люди с ролью и годами, места, главная страна —
по большинству мест). Сверь с `clean-script.txt`, дополни, покажи Nurlan на подтверждение. Реестра нет — заполни по сценарию сам:
- тема эпизода одной строкой;
- **эпоха** — основные годы (например, 1984–1992);
- места и страны (главная страна — для поиска кадров);
- ключевые люди — **имя + роль + годы** (William Webster, директор ФБР, 1978–1987);
- сцены вне основной эпохи (флешбэки, «40 лет спустя»);
- что в кадре недопустимо (кроме общих правил «Проверки кадров»).
Паспорт — `06_montage\context.json`. Им пользуются разметка, поиск и проверка кадров. Главная страна эпизода — отсюда, не угадывается.

**Пополнение справочников (тут же, на шаге 0):** `passport` показывает места и страны реестра, которых нет в `data\places.json` / `data\countries.json` («Новое место: Camp Century (77.1797, -61.1097)»). Показать Nurlan, после «да» — `passport --apply`. Мест из сценария, которых нет в реестре, — дописать в список вручную. Только английские названия.

**1. Проверь сценарий**
- Вход — `clean-script.txt`: чистый текст, ровно то, что будет озвучено. Не менять ни на слово (по нему потом сверяется озвучка).
- Главы придумываешь сам по смыслу текста.
- Цифры, даты, имена — сверить с надёжными источниками. Сомнительное показать Nurlan с безопасной формулировкой; по смыслу без согласия не править.

**2. Разметь сценарий** (метки — в `README.md`, раздел «Метки»)
- Главы `[ГЛАВА]`, инфографика по цифрам `[СЧЁТЧИК] [ДИАГРАММА] [ТАЙМЛАЙН] [СПИСОК] [КАРТА]`, цитаты `[ЦИТАТА]`, имена `[ПОДПИСЬ]`, даты `[ДАТА]`.
- Кадры — `[НАЙТИ: запрос по-английски | фото/видео/хроника]`. Поиск идёт **сначала по своим папкам** (`02_characters`, `03_generated`, `05_footage`), потом в интернете.
- **Люди, места и объекты из реестра — по имени из `cast.json`** (`[НАЙТИ: Frank Camper 1985]`): фото Nurlan `frank_camper_01.jpg` найдётся первым, без проверки глазами. `[КАРТА]` — координаты из `places.<имя>.map` реестра.
- **Запросы `[НАЙТИ]` — с контекстом из паспорта, никогда обобщённо.** Не «US president», а «Ronald Reagan 1985»; не «FBI director», а «William Webster FBI 1985»; не «Indian prime minister», а «Rajiv Gandhi 1985». Роль → конкретное имя, плюс год или эпоха. Для общих планов (лес, улица, суд) — эпоха в запросе: «1980s courtroom», «1980s New Orleans street».
- Сцена вне основной эпохи — метка `[ЭПОХА: 1972]` **сразу после** метки сцены (`[НАЙТИ]`, `[КАРТИНКА]`, `[СЦЕНА]`), как `[ПОДПИСЬ]`. До неё — прилипнет к предыдущей сцене.
- Часть кадров — генерация: `[КАРТИНКА: промт по-английски]` — для того, чего нет на стоках или что на стоках шаблонно (реконструкции, атмосфера, метафоры). Только стоки = шаблонный контент.
- Смена типа кадра каждые 10–20 с. Темп и правила титров — по `STYLE.md`.
- **Видео — стараться вставить** (решение Nurlan, EP-10): техника, хроника событий, города и улицы — `| видео` / `| хроника`. Не нашлось — картинка (Gen), это не проблема; долго не искать. Ориентир — как в EP-08…10: 7–10 клипов на ролик уже достаточно.
- **Начало ролика — видео** (решение Nurlan, EP-10, записано после EP-11: пожелание потерялось, в v1 первые 14 мин — без единого видео): хук и первые ~5 мин — **не меньше 5–6 видео**. Для них искать отдельно и дольше, сток подходит: другой город вместо нужного («вечерний Нью-Йорк» → любой вечерний город), случайная семья у телевизора, руки с деньгами, касса, торговый зал — всё годится. Запросы — общие, без эпохи и имён (`family watching tv at night | видео`). Gen в начале — только если по шоту видео нет совсем. Перед сводкой плана — посчитать видео в первых 5 мин и назвать число Nurlan.
- В `[КАРТА]` всегда давать координаты: `Город(шир, долг)`.
- **Имя из реестра — целиком, как в `cast.json`** (`Walter Cronkite CBS 1961`, не `Cronkite CBS`; `Hans Christian Hansen 1957`): фото из `02_characters` подставляется, только если в запросе есть все слова имени (EP-08).
- **У каждого шота свой запрос.** Одинаковый `[НАЙТИ]` в разных шотах делит одни и те же файлы (EP-08: Krag в шотах 34 и 57, разрез PM-2A трижды) — добавлять год, ракурс, деталь.
- Числа и даты на экране — **по-американски** (`1,000,000`, `August 18, 1959`), см. `STYLE.md`. Пометку `| реконструкция` не ставить — пометок ИИ на кадрах нет.
- **`[СЧЁТЧИК]` — всегда три поля** (EP-10): `[СЧЁТЧИК: $800 | a month | alimony and child support]`; из двух полей подписью становится «$». Процент — `[СЧЁТЧИК: 90 | % | of Polamco owned by the Polish state]`.
- **Короткая фраза (≲ 2 с: «Los Angeles.», «Who was on the other side?») — не отдельной сценой**, а вместе с соседней (EP-10: 4 кадра короче 2 с).

**2а. Генерация — сразу после разметки** (с EP-08 делает Claude, не Nurlan).
Все `[КАРТИНКА]` попадают в `ep-N-shots.json` с полем `generate` (`tools\shots_from_script.py ep-N` — сам скрывает фамилии archive_only, иначе Gen пропустит шот) → `ve.py gen ep-N` (ImageGenerator, ~$0,01 за кадр) → посмотреть глазами → вписать `[СЦЕНА: 32-g]`. Люди из реестра с `face_policy` = `archive_only` не генерируются. Задание `ai01…` / файл `_generate.txt` больше не нужны.

**2б. Озвучка — сам, без напоминаний** (решение Nurlan, EP-09).
Как только есть `00-script\clean-script.txt`, а в `01_vo\` ещё нет `vo_*.mp3`, — запустить скилл **`elevenlabs-vo`** в режиме VideoEditor (канал, папка и тексты известны — ничего не спрашивать) параллельно с поиском (поиск — в фоне). Единственная остановка — **экран утверждения с ценой в кредитах: ждать «ок» Nurlan**, это расход. Нужен подключённый коннектор ElevenLabs; если его нет в сессии — сказать одной строкой. Озвучка уже есть — не трогать; переозвучить кусок — только по просьбе (`vo_07` целиком, под тем же именем).
**Длительность озвучки — только `ffprobe` по скачанным mp3 + паузы `voice_parts.json`** (EP-12): `duration_secs` в ответе ElevenLabs завышен ~на 5% (сказали «29:53», на деле 28:24 → Nurlan зря просил тишину).

**Удочка (тизер следующего эпизода) — обязательна, как музыка** (решение Nurlan, EP-10: удочку пропустили).
Текст — `00-script\udochka.md` (вариант «✅ для записи», EN) → отдельный `vo_outro`, сцена тизера в конце `script.txt`, пауза 4,5 с перед ней. Файл главнее строки «удочка не написана» в `sound-vo.md` (hl-script пишет его позже). Нет `udochka.md` и нет удочки в `clean-script.txt` — **спросить Nurlan: «А удочки нет что ли?»** до озвучки, не молча идти дальше.

**2в. Портреты людей — сам, до поиска** (с EP-10, решение Nurlan после EP-09).
`ve.py refs ep-N` → референсы людей из реестра в `02_characters\refs\s_<id>_1` (Википедия, файлы Commons из `archive.where`, поиск Commons «имя + год ±3») → посмотреть лист `work\person_refs.jpg` глазами (эпоха, тот ли человек по подписи) → `ve.py regravure ep-N` → гравюры `02_characters\<id>_01.png` встают во все шоты человека при поиске. Nurlan докладывает только тех, кого `refs` не нашёл (EP-09: McGoff, Rhoodie, Mostert, Erasmus). Обрезанный референс — `regravure --note` («дорисуй лицо по центру»).
**`refs` не нашёл — искать самому, до Nurlan** (EP-11, EP-12: 13 из 18 за ~15 мин): поиск картинок Bing во встроенном браузере (ссылки на оригинал — поле `murl` в атрибуте `m` у `a.iusc`), Commons — с паузой ≥ 4 с между запросами (иначе 429). Два лица в кадре — обрезать до нужного. **Тёзки:** сверять год рождения с возрастом на фото (EP-12: везде José Isabel Blandón-сын, политик 2010-х, вместо отца, свидетеля 1988 — его прислал и Nurlan). Нет нигде — шот без лица и без `[ПОДПИСЬ]` (Nurlan: «незначительный человек»).

**3. Найди кадры и покажи пробелы**
- Запустить поиск. Пустые сцены закрывать своими кадрами шота (`[СЦЕНА: файл]`), не текстовыми карточками.
- Проверить обзор найденного глазами (см. «Проверка кадров»).
- Пробелы — **только списком шотов** (решение Nurlan, EP-08), не общими «найди 4 кадра по …»:
  - в `script.txt` у каждой медиа-сцены комментарий `# shot N` (номера постоянные, при правках не перенумеровывать);
  - `06_montage\output\ep-N-shots.json` — один файл и для поиска, и для генерации, сверху вниз. Поля: `shot_no`, `scenario_text` (дословно), `epoch`, `day_time`, `place`, `expected` (по-русски: что должно быть в кадре), `query` (по-английски), `kind` (видео / фото / любое — пожелание, не требование), у генерации ещё `generate` (промт; Nurlan сам ищет источник композиции по `query`). В файл — только незакрытые шоты;
  - Nurlan называет файлы по номеру: `12.jpg`, `12.mp4`, `12_2.jpg` (ещё кадр), `12_pd.jpg` (public domain, Commons). Вид может отличаться от `kind`. Найденное → `05_footage`, сгенерированное → `03_generated`;
  - **`s_12.png` / `s-…` — исходник для генерации, в монтаж не брать** в любой папке (программа их пропускает), как и подпапки `source_for_gen`;
  - принёс файлы → вписать в разметку `[СЦЕНА: 12, 12_2]` вместо `[НАЙТИ]` / `[КАРТИНКА]` этого шота;
  - **файлы ищи везде в папке эпизода** — Nurlan может положить их в `06_montage\output\` рядом с json: разложить по `05_footage` / `03_generated` / `source_for_gen` и сказать ему одной строкой.
- **Пробелы закрывать по-быстрому (EP-08: 79 пустых шотов → 0 за вечер, $0,61):**
  1. мягкий поиск (`find`) — закрывает людей, города, технику; несвободные кандидаты сами падают в `06_montage\refs\s_<шот>_N.jpg`;
  2. Nurlan кладёт образцы из браузера (Google / Яндекс) в `refs\` — имена приводить к `s_<шот>_<N>.<ext>` (`s-114.jpg` → `s_114_1.jpg`, `s-72-2.jpg` → `s_72_2.jpg`);
  3. у шота с образцом `kind: видео` → `любое` (ReGen видео-шоты пропускает);
  4. `ve.py regen ep-N` → глазами → `[СЦЕНА: 14-1-rg]`; готовый кадр без `s_` в `refs` (монета `119.png`) — мелкий → в ReGen, крупный → в `05_footage`.
  Узкая тема (Camp Century, интерьеры, журналы) в открытых архивах почти не находится — на неё сразу закладывать ReGen.

### ImageReGen (Nurlan называет его так)
Для чего: обход шаблонности стоков и чужих прав — новый снимок по мотивам референса, а не копия.
- Идёт по `06_montage\output\ep-N-shots.json`; шот без референса в `refs\` — пропускает. Один референс — одна итерация.
- **Шоты с `kind` = «видео» — ReGen и Gen не обрабатывают** (нужен видеоряд, не картинка).
- Итерация: `gpt-4.1-mini` смотрит референс + задание шота → промт правок (сцена референса сохраняется; новый ракурс, 16:9, время суток и детали задания; всё физически правдоподобно для места и эпохи) → `gpt-image-2.5-sunburst` (референс + промт) → картинка.
- **Проверка правдоподобия:** `gpt-4.1-mini` оценивает результат 0–10. **≥ 7 — принято**; ниже — одна перегенерация по исправленному промту, сохраняется лучший вариант (оценки — в журнале). Claude в проверке не участвует — это делает сам скрипт.
- Параметры: **1280×720 (16:9), quality `medium`, PNG**. Стиль — просто «photograph»; плёнка эпохи (35 мм, Polaroid, ч/б 30-х) — только если правда нужно. Никаких постоянных «зерно, выцветание».
- Не просить «убери водяной знак» — в промте только «без подписей, водяных знаков и логотипов поверх фото» (новый кадр, а не чистка чужого фото). Надписи внутри сцены (таблички, номера, приборы) — можно, если верны по заданию.
- **Имена результатов в `03_generated`:** ReGen — `<шот>-<N>-rg.png` (`63-1-rg.png`, `63-2-rg.png`); ImageGenerator (без референса) — `<шот>-g.png` (`32-g.png`). В сценарии подключать как `[СЦЕНА: 63-1-rg]`.
- Люди из `cast.json` с `face_policy: archive_only` — шот не перерисовывается.
- Журнал и стоимость (из `usage` ответов OpenAI): `06_montage\work\regen.json`; в конце прогона — строка «запросов N — $X (за всё время по эпизоду $Y)». Ориентир: ~$0,03–0,05 за картинку.
- Шоты только с `generate`, без референса, — **ImageGenerator**, не этот tool.
- **Документ, а не лицо** (EP-09): ReGen пропускает шот, если в тексте задания есть фамилия человека с `archive_only` — даже когда в кадре первая полоса газеты или доклад. Для таких шотов убрать фамилию из полей задания в `ep-N-shots.json` (`scenario_text`, `expected`, `query`; сценарий не трогать). Живые лица реальных людей — не ReGen, а ReGravure.
- **Отказ модерации OpenAI** (HTTP 400, EP-09: урна для голосования) — не повторять тот же образец: образец в `refs\s_x_…`, шоту — `generate` нейтральным промтом → Gen.

### ImageGenerator / Gen (Nurlan называет его так)
- Идёт по `ep-N-shots.json`: шоты с `generate` **и без** референса в `refs\` (с референсом — ReGen).
- Первый промт — **без ИИ**: `generate` Nurlan как есть + «16:9 photograph, period-accurate.» (для схем, карт, гравюр, картин, плакатов — «16:9, period-accurate.» без photograph). Тип картинки определяется по тексту `generate`, не по полю `kind` (там у схем тоже «фото»); проверка правдоподобия и ReGen тоже следуют типу из задания.
- Генерация с нуля (`gpt-image-2.5-flare` — быстрая генерация; ReGen — `sunburst`, 1280×720, `medium`, PNG) → та же проверка правдоподобия, что в ReGen (≥ 7 — принято; ниже — `gpt-4.1-mini` переписывает промт с учётом ошибки → одна перегенерация).
- Результат `03_generated\<шот>-g.png`; журнал и стоимость — общий `work\regen.json`.

### ReGravure (Nurlan называет его так) — с EP-09
Для чего: один стиль канала для всех лиц (гравюра) и нет чужих прав на фото. Одна гравюра закрывает все шоты человека.
- Референсы — `ep-N\02_characters\refs\s_<id>_N.jpg` по id из `cast.json` (`s_john_mcgoff_1.jpg`; понимает и `s-<id>.jpg`). Подпапка в каталог кадров не попадает.
- **Одна гравюра на человека** — по первому референсу. Нужен другой вариант — перегенерировать отдельно, с нужной правкой.
- Промт — **промт Nurlan слово в слово** (`GRAVURE_PROMPT` в `tools\image_regravure.py`): гравюра, перекрёстная штриховка, сине-серый фон, без сепии и растра, 16:9. Меняется только his / her (пол по референсу, `gpt-4.1-mini`).
- `gpt-image-2.5-sunburst` (референс + промт), 1280×720, `medium`, PNG → проверка `gpt-4.1-mini`: сходство лица + стиль, ≥ 7 — принято; ниже — ещё одна попытка с тем же промтом, сохраняется лучшая.
- Результат — `02_characters\<id>_01.png` (исключение из правила «в 02_characters пишет только Nurlan», решение Nurlan, EP-09). Свой кадр `<id>_NN` уже есть — пропуск (`--force` — перезаписать `_01`).
- `face_policy: archive_only` ReGravure **не блокирует** (гравюра по фото — как у Nurlan на EP-08). После прогона — `index`, затем `find` (подставит гравюры в шоты по имени).
- Журнал и стоимость — общий `work\regen.json` (`tool: regravure`). Ориентир ~$0,04 за портрет.

Настройки для кода — `settings.json` (машинная копия `STYLE.md`; менять оба вместе).

## Проверка кадров (обязательно, глазами)
**Мягко, без перфекционизма** (решение Nurlan, EP-08: «мы не корпорация, блогер на пенсии»). Кадр, который в целом иллюстрирует текст, — берём.

Отбраковывать всегда:
- **жестокость** — кровь, раненые, бодикамеры, плашки «graphic content» (YouTube режет рекламу);
- **реальные политики не той эпохи / не те люди**;
- **чужие логотипы, водяные знаки, плашки телеканалов**;
- **явный мусор** — не тот предмет (глобус вместо Гренландии, шахта вместо ледового туннеля), чёрный кадр, мелочь меньше ~700 px;
- **повторы одного кадра**, текстовые карточки вместо картинок, кадры короче 2 с.

Допустимо (отметить, но не браковать): современное фото старого места или здания, современные детали на фоне, похожая природа не той страны, неточности в генерации. Эпоху «старит» LUT канала.

**Как браковать** (EP-09): монтаж берёт найденное по файлам `06_montage\media\find_*`, а не по `work\found.json` — брак **удалять файлом из `media\`** (и из `found.json`); иначе отбракованный кадр попадёт в ролик. Шот, который должен ждать файл Nurlan, — `[СЦЕНА: N]` вместо `[НАЙТИ]` (иначе поиск найдёт тот же брак снова). **Шот, оставшийся пустым после брака, — сразу `[КАРТИНКА]` (Gen) или `[СЦЕНА]`**; новый `[НАЙТИ]` — только другими словами (EP-12: повторный find принёс 9 уже удалённых файлов — хромакей-шлагбаум, британских гвардейцев, CGI C-130). В стоках по «military plane / checkpoint / soldiers marching» — частый мусор: CGI, хромакей, чужие армии. После любого поиска, удаления или новых своих кадров — **`analyze`** (голос не менялся — секунды) **перед `empty` и `plan`**: список материалов берётся из него (EP-09: 154 ложных «пустых» сцены, а удалённый кадр уронил бы рендер).

## Публикация — не наша зона
Загрузку, «AI use», доступ «Ограниченный» и проверку прав ведёт **Video-Wrapper** — Nurlan об этом не напоминать (решение Nurlan, EP-11). Наше — только музыка лицензированная и полный блок авторства в описании.

## Правила
- Ключи — только в `keys.json`. Никуда не отправлять, в ответах не показывать.
- Ничего не удалять на компьютере, кроме своих рабочих файлов в `06_montage\` эпизода. Чужие файлы и настройки Windows не трогать.
- Код программы менять только когда без этого никак — сначала объяснить Nurlan, что и зачем.
- Python: окружение `.venv` (Python 3.14), запуск `.venv\Scripts\python.exe`. Зависимости — `requirements.txt`. Кэши: `PIP_CACHE_DIR=D:\YouTube-Studio\.cache\pip`, `HF_HOME=D:\YouTube-Studio\.cache\hf` (модель Whisper `medium` уже скачана туда).
- Позже (после отладки): опция распознавания через OpenAI Whisper API (`whisper-1`, ~$0,12 за 20 мин, ~1 мин вместо 7).
- Видеокарты NVIDIA нет: распознавание речи — процессор + модель `medium`. Рендер 20 минут видео ≈ 40 минут.
- Платные API: OpenAI (pay-as-you-go) — для просмотра кадров. Gemini API — бесплатный уровень, низкие лимиты (подписка Gemini Pro лимиты API не повышает). Обходить лимиты несколькими аккаунтами нельзя — нарушение правил Google.
