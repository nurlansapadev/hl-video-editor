# VideoEditor 2.0 — справочник программы

Порядок работы и правила — в [`CLAUDE.md`](CLAUDE.md). Стиль — [`STYLE.md`](STYLE.md). Здесь — метки сценария и устройство программы.

## Метки в сценарии (`ep-N\06_montage\script.txt`)

Метки пишутся в квадратных скобках и **не озвучиваются**. Строки, начинающиеся с `#`, — комментарии. Метка относится к тексту после неё — до следующей метки сцены. Текст озвучки между метками — дословно из `00-scriptean-script.txt`.

### Метки, которые начинают новую сцену
| Метка | Что делает |
|---|---|
| `[НАЙТИ: запрос | вид | сколько]` | Сцена из найденных кадров. Вид: `фото` (по умолчанию), `видео`, `хроника` (архивные/новостные), `любительское`, `газеты` (США до 1928), `фильм` (кинохроника → `library\`). Сколько — необязательно, по умолчанию по длине текста (~1 кадр на 6 с). Запрос — по-английски, с именем и годом (`Ronald Reagan 1985`, `1980s courtroom`). Несколько `[НАЙТИ]` подряд — одна сцена |
| `[КАРТИНКА: промт по-английски]` | Сцена со сгенерированной картинкой `ai01`, `ai02`… (по порядку меток). Длинная сцена — ещё `ai01b`, `ai01c`. `| реконструкция` в конце — плашка «AI reconstruction» |
| `[СЦЕНА]` / `[СЦЕНА: 064_Hotel, 065]` | Сцена со своими кадрами из `05_footage`, `03_generated` или `02_characters` (имя без расширения). Если есть и `.jpg`, и `.mp4` с одним именем — берётся видео. Кусок видео с нужной секунды: `[СЦЕНА: film@1:23]` |
| `[ГЛАВА: Название]` | Заставка главы + таймкод в файле глав для YouTube |
| `[ЗАГОЛОВОК: Название | подзаголовок]` | Заставка; в самом начале ролика играет под музыку до голоса |
| `[ТАЙМЛАЙН: Заголовок | 1984 — Golden Temple | 1985 — Washington]` | Линия времени; точка появляется, когда диктор называет год или место |
| `[СПИСОК: Заголовок | Пункт 1 | Пункт 2 — пояснение]` | Список; пункт появляется на «first / second…» или на ключевых словах |
| `[СЧЁТЧИК: 150 000 | copies | подпись]` | Крупное число с анимацией счёта (понимает `6,5 million`, `$350`) |
| `[ЦИТАТА: Текст | автор]` | Цитата крупно |
| `[КАРТА: Заголовок | Toronto(43.68, -79.63) > Montreal(45.47, -73.74)]` | Карта с маршрутом; точки появляются, когда звучит название. **Координаты — всегда**; без них берутся из `data\places.json` |
| `[ДИАГРАММА: Заголовок | A = 3,2 | B = 1,4]` | Столбики; `A = 51,8 → 108,3` — было → стало |
| `[ФИНАЛ: Вопрос зрителям | призыв]` | Концовка с вопросом и призывом |

### Метки внутри сцены (ставятся **после** метки сцены)
| Метка | Что делает |
|---|---|
| `[ПОДПИСЬ: Имя | кто это]` | Плашка «кто это» внизу кадра — при первом появлении человека |
| `[ДАТА: May 13, 1985]` | Дата в углу кадра |
| `[НАДПИСЬ: текст]` | Надпись по центру кадра |
| `[ЭПОХА: 1972]` | Эпоха этой сцены, если она вне основной (паспорт эпизода) — для поиска и проверки кадров |
| `[ФОН: 03]` | Фон для инфографики — свой кадр |
| `[КОЛЛАЖ]` / `[КОЛЛАЖ: доска / сетка / сплит]` | Несколько кадров сцены на одном экране (2–4 материала) |
| `[АКЦЕНТ]` | Плавный наезд камеры в этот момент |
| `[ПЕРЕХОД: растворение / затемнение / сдвиг / зум / шторка / размытие / склейка]` | Переход к следующему кадру |
| `[ЗВУК: файл.mp3]` | Звуковой эффект из `06_montage\sfx` в этот момент |

## Где что лежит
```
VideoEditor_2.0\                      код и настройки (данных эпизодов нет)
  tools\ve.py                         пульт команд (вызывает Claude по CLAUDE.md)
  tools\finder.py                     поиск кадров: свои папки → интернет, проверка глазами, отчёт work\find_report.txt
  tools\sources\                      источники поиска: один файл = один источник (commons.py, pixabay.py, nasa.py…);
                                      контракт — sources\__init__.py; порядок и выключение — settings.json → finder;
                                      ddg.py (DuckDuckGo), tavily.py (запасной) — только образцы для ReGen,
                                      в ролик напрямую не идут; счётчик Tavily — data\tavily_usage.json
  tools\find_history.py               журнал поиска по эпизодам (data\find_history.jsonl, find_requests.jsonl)
                                      и `ve.py findstats` — вклад источников, пустые шоты, подсказки
  tools\planner.py                    режиссёрский план (plan.json)
  tools\scriptparse.py                разбор меток, привязка текста к озвучке
  tools\local_index.py                каталог описаний своих кадров
  tools\image_regenerator.py          ImageReGen: новые фото по референсам refs\ (OpenAI) → 03_generated\
  tools\image_generator.py            ImageGenerator (Gen): фото с нуля по полю generate (OpenAI) → 03_generated\
  tools\transcribe.py, audio.py       распознавание речи, звук
  tools\regions.py, gazetteer.py      страны и места (данные — data\)
  engine\                             движок рендера (Remotion)
  settings.json                       настройки для кода (копия STYLE.md)

production\honest-lies\ep-N\          создаёт hl-script (new_episode.py), с EP-08
  00-script\clean-script.txt          текст озвучки — вход этапа 1          ┐
  01_vo\                              wav ElevenLabs                        │
  02_characters\                      cast.json + фото <id>_01.jpg          │ входы
  03_generated\                       гравюры, Veo, картинки [КАРТИНКА]     │ (только читаем)
  04_music\                           фоновая музыка                        │
  05_footage\                         архив и сток                          ┘
  06_montage\                         работа программы:
    ep-N_vK.mp4       готовые версии
    context.json      паспорт эпизода (черновик — из cast.json)
    script.txt        размеченный сценарий
    empty_scenes.json решения по пустым сценам
    plan.json         план монтажа
    media\            найденные + ссылки на свои кадры и картинки ai
    footage_index\    каталоги описаний своих папок (05_footage\, 03_generated\, 02_characters\)
    work\             служебное: found.json, find_log.txt, found_sheet.jpg, transcript.json, check.jpg
    output\           ep-N.mp4, ep-N.srt, ep-N_chapters.txt, ep-N_credits.txt, ep-N_generate.txt
```

## Лицензии кадров
Только общественное достояние, CC0, CC BY (автор в блоке авторства), лицензии Pixabay / Unsplash / Pexels. NC и ND — никогда; CC BY-SA — только если `"finder": {"allowShareAlike": true}`. Свои кадры — без подписи и вне блока авторства.
